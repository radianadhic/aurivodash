Aurivo Dash — dashboard perbankan bergaya AdminLTE v3, dibangun ulang dengan Tailwind CSS v4

Tema lengkap: sidebar bertingkat, navbar dengan notifikasi, kartu statistik, tabel pintar tanpa plugin, formulir, kanban drag & drop, grafik SVG buatan sendiri, dark mode, dan 7 pilihan skin. Semua berkas — CSS, JS, ikon, font — tersimpan lokal, jadi template berjalan penuh tanpa koneksi internet maupun CDN.

Yang membuatnya berbeda

Benar-benar offline

Tailwind dikompilasi ke satu berkas CSS; ikon, font, Alpine, dan SortableJS disalin ke assets/. Bisa dibuka lewat file://.

Dark mode & 7 skin

Warna aksen dan warna sidebar diatur lewat CSS variable, bisa diganti langsung dari panel kanan dan disimpan di localStorage.

Grafik tanpa library

± 30 KB modul SVG buatan sendiri: line, area, bar, stacked, horizontal, donut, radial, sparkline — lengkap dengan tooltip dan animasi.

Tabel pintar siap pakai

Pencarian, sortir per kolom, paginasi, dan pilih baris massal — cukup tambahkan atribut data-datatable pada <table>.

Kanban drag & drop

Memakai SortableJS lokal dengan contoh payload onEnd yang siap dikirim ke API Anda.

Asisten AI yang selalu muncul

Widget obrolan melayang di kanan bawah SEMUA halaman (termasuk aplikasi nasabah). Jawaban simulasi berjalan offline; sambungkan model sungguhan lewat window.AIChat.setProvider(fn).

Struktur mudah dipelihara

Halaman disusun dari partial (sidebar.html, navbar.html, dst.) dengan skrip build Node sederhana, hasilnya HTML statis.

Cara memakai

A. Langsung pakai (tanpa Node)

  1. Ekstrak folder template.
  2. Buka pages/index.html (klik dua kali) di peramban.
  3. Selesai — CSS, ikon, dan font sudah ter-compile.
Dibuka lewat file:// semua fitur tampilan jalan. Untuk localStorage dan IntersectionObserver paling stabil, jalankan server statis kecil: npm run serve.

B. Mengubah kode

npm install          # sekali saja
npm run dev          # Tailwind watch → assets/css/app.css
npm run pages        # bangun ulang HTML dari src/pages
npm run icons        # regenerate ikon ke assets/js/icons.js
npm run build        # CSS produksi (minified)
npm run serve        # server statis di :8080
  • src/input.css — token tema, skin, dan komponen (design system)
  • src/pages/*.html — isi halaman + front-matter
  • src/partials/ — sidebar, navbar, footer, panel kontrol, overlay
  • assets/js/app.js — DataTable, kartu, toast, format angka Indonesia
  • assets/js/charts.js — mesin grafik SVG

Pintasan keyboard & catatan lisensi

  • Ctrl + K fokus ke pencarian global
  • Ctrl + B kecilkan / besarkan sidebar
  • . ganti mode terang / gelap
  • Esc tutup menu, modal, atau panel
