Mini Grid 4 — aksi per baris. Tanpa checkbox sama sekali (select: false): setiap baris punya ikon Detail, Edit, dan Hapus (rowActions: true). Formulir Tambah/Edit memakai 3 kolom (formCols: 3) yang otomatis menumpuk di layar sempit.

Penugasan Proyek

Gunakan ikon di kolom Aksi pada tiap baris · tombol Filter untuk menyaring kolom Prioritas/Status

0 baris aksi per baris

MiniGrid siap.

Fitur contoh ini

  • Ikon Detail, Edit, Hapus pada tiap baris
  • Tanpa checkbox (select: false) — tidak ada tombol mati
  • Formulir 3 kolom responsif (formCols: 3)
  • Mode Detail hanya-baca (semua input disabled)
  • Pill warna untuk Prioritas & Status via render
  • Filter terpusat + bantuan (filterForm, help)
  • Modal bisa digeser (seret bilah judulnya)
  • Ekspor XLSX (header tebal + pane beku + AutoFilter)

Kode inti

MiniGrid({
  el: "#minigrid-4",
  columns: kolomProyek,
  data: rowsProyek,
  height: 380, pageSize: 8,
  select: false,          // tanpa checkbox & tanpa seleksi massal
  rowActions: true,       // ikon Detail / Edit / Hapus di kolom Aksi
  add: true, editForm: true, formCols: 3,
  filter: false, filterForm: true, help: true,
  onAdd: function (r) { r.id = nomorBerikutnya(); return r; }
});
Kapan dipakai? Bila pengguna berinteraksi per baris (detail satu record) dan seleksi massal justru membingungkan — mis. daftar penugasan, tiket, atau daftar transaksi yang setiap barisnya punya aksi sendiri.
