Report Viewer — penampil laporan siap cetak. Halaman ini memuat aplikasi SatuReport Viewer yang sama dengan versi offline-nya: menampilkan layout hasil Report Design, contoh bawaan, atau file paket .satureport.json. Lengkap dengan pratinjau per halaman, zoom fit dan 1:1, cetak/PDF, serta ekspor XLSX. Asetnya di-vendor lokal di folder assets/satureport/ dari repositori github.com/radianadhic/satureport.

Bingkai Report Viewer

iframe · SatuReport
Tombol Galeri Contoh di toolbar aplikasi membuka 12 laporan siap pakai — semuanya tanpa jaringan.

Sumber data yang bisa dipilih

4 cara
  • Bahasa aplikasi mengikuti tombol bahasa template — ganti bahasa di navbar, bingkai ikut berganti.
  • Tampilan aplikasi selalu terang karena punya tema sendiri, jadi tidak ikut mode gelap template.
  • Semua proses berjalan di peramban — tidak ada data laporan yang dikirim ke server.
