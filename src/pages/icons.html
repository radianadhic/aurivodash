Ikon tersedia

Semua ikon disimpan sebagai path SVG di assets/js/icons.js (di-generate oleh npm run icons dari paket Bootstrap Icons, lisensi MIT). Pemakaian: <i data-icon="cart-check" data-size="18"></i> — tanpa font ikon eksternal, tanpa emoji, tanpa permintaan jaringan.

Ikon dengan kata kunci tersebut tidak ada. Tambahkan nama ikonnya ke tools/build-icons.mjs lalu jalankan npm run icons.

Klik salah satu ikon untuk menyalin markup <i data-icon="…"> ke clipboard.
