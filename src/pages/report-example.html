Report Example — galeri contoh laporan. Setiap kartu adalah contoh siap pakai: thumbnail-nya dirender langsung oleh mesin SatuReport, bukan gambar. Dari sini laporan bisa langsung dibuka di Report Viewer atau disunting di Report Design — cukup tekan satu tombol. Sumbernya repositori github.com/radianadhic/satureport yang di-vendor lokal di folder assets/satureport/.

Galeri contoh laporan

iframe · SatuReport
Tombol ▶ Viewer membuka laporan, ✎ Desainer membukanya untuk disunting, ⬇ mengunduh paket .satureport.json.

Isi galeri

12 contoh

Invoice / Faktur Penjualan

Faktur multi-halaman: header dan footer berulang, kolom item, serta ringkasan total.

Slip Gaji Karyawan

Dua kolom pendapatan dan potongan dalam satu baris berulang per karyawan.

Surat Jalan / Delivery Order

Dokumen pengiriman barang dengan barcode nomor resi dan daftar barangnya.

Laporan Stok per Kategori

Menampilkan Sub Group: setiap kategori punya subjudul dan daftar barangnya sendiri.

Label Pengiriman Multi-Paket

Label resi ukuran kecil — content berulang mencetak beberapa label dalam satu halaman.

Kwitansi Pembayaran

Kwitansi klasik dengan kotak terbilang, kotak total gelap, dan area tanda tangan.

Laporan Penjualan + Grafik

Tabel penjualan bulanan dengan grafik garis tren realisasi dibanding target.

Pivot Table / Crosstab

Crosstab otomatis dari data mentah: baris kota, kolom bulan, plus subtotal.

Direktori Pengguna dari Data API

Layout untuk endpoint JSON API — tombol reload mengambil datanya ulang.

Laporan Query Kustom

Paket layout + data berisi query dan endpoint: viewer mengirim query ke endpoint.

Laporan Berparameter

Laporan disembunyikan sampai form parameter seperti Tahun dan Kota diisi.

Viewer Memuat File dari Server

Contoh pemakaian parameter url: satu berkas .satureport.json dimuat lewat fetch.
