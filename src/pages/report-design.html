Report Design — desainer laporan visual. Susun Report Header, Content berulang, Sub Group, dan Report Footer langsung di kanvas berukuran halaman (mm), lalu ekspor hasilnya ke PDF atau XLSX. Aplikasi SatuReport di-vendor lokal di folder assets/satureport/ (github.com/radianadhic/satureport) dan berjalan di dalam bingkai di bawah ini — seluruh asetnya ikut di halaman aplikasi, jadi tetap 100% offline.

Kanvas Report Designer

iframe · SatuReport
Layout disimpan di IndexedDB peramban Anda (bukan server) — aman untuk uji coba.

Yang bisa dikerjakan di halaman ini

SatuReport
  • Kanvas halaman berukuran mm dengan grid dan snap — atur lebar halaman serta margin lewat panel kanan
  • Tiga band utama: Report Header, Content yang berulang per baris data, dan Report Footer — ditambah Sub Group
  • Elemen siap pakai: teks, gambar, barcode, grafik, garis, dan pivot table
  • Seret field dari panel Data Source ke kanvas untuk membuat item ter-binding
  • Sumber data tiga macam: JSON manual, endpoint API, atau query kustom yang mendukung parameter
  • Field sistem: nomor halaman, nomor baris, jumlah baris, dan tanggal cetak
  • Undo/redo, duplikat dengan Ctrl+D, geser dengan tombol panah, zoom dengan Ctrl+scroll, dan auto layout dari data
  • Simpan layout ke IndexedDB peramban, ekspor paket .satureport.json, cetak/PDF, dan ekspor XLSX
  • Test preview mengambil data dari sumber (API atau query) lalu merendernya langsung di kanvas

Catatan

  1. Mulai dari nol dengan tombol Report Baru, atau muat contoh lewat tombol Sample di toolbar aplikasi.
  2. Seret field dari panel kiri ke kanvas, lalu atur gaya teksnya di panel kanan.
  3. Buka Galeri Contoh untuk melihat 13 template siap pakai, termasuk contoh Sub Report dan contoh yang bisa dimuat ke viewer.
