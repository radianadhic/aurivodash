Mini Grid 3 — alur persetujuan. Baris filter di bawah judul dimatikan (filter: false) dan digantikan satu form Filter terpusat (filterForm: true). Dua aksi kustom Approve / Reject muncul di toolbar grid dan bekerja pada baris terpilih (need: 'some'), plus tombol Bantuan berisi panduan singkat.

Pengajuan Cuti

Pilih baris lalu klik Approve/Reject di toolbar grid · tombol Filter untuk menyaring banyak kolom sekaligus

0 baris aksi kustom

MiniGrid siap.

Fitur contoh ini

  • Aksi kustom di toolbar: Approve, Reject (mengubah kolom Status)
  • need: 'some' — aktif hanya bila ada baris terpilih
  • Form Filter terpusat: field + operator + nilai, gabungan AND/OR
  • Badge jumlah kondisi aktif + Reset
  • Tombol Bantuan berisi panduan pemakaian grid
  • Formulir 2 kolom (formCols: 2) untuk Tambah/Edit
  • Status berwarna otomatis (render kustom)
  • Ekspor PDF lanskap otomatis + CSV/XLSX dari menu grid

Kode inti

MiniGrid({
  el: "#minigrid-3",
  columns: kolomPengajuan,
  data: rows(40),
  height: 360, pageSize: 10,
  crud: true, edit: true,
  filter: false,        // tanpa baris filter di bawah judul
  filterForm: true,     // …dituangkan ke satu form lewat tombol Filter
  help: true, formCols: 2,
  actions: [
    { id: "approve", label: "Approve", icon: "ok", need: "some",
      fn: function (rows, g) { rows.forEach(r => r.status = "Approved"); g.render(); } },
    { id: "reject",  label: "Reject",  icon: "no", need: "some",
      fn: function (rows, g) { rows.forEach(r => r.status = "Rejected"); g.render(); } }
  ]
});
Catatan. Contoh ini tidak menyimpan perubahan ke server — semuanya berjalan di sisi peramban (data contoh deterministik).
