Catatan implementasi

Inisialisasi ada di bagian bawah halaman ini. Untuk proyek nyata, kirim urutan kolom + posisi kartu ke backend pada event onEnd: 

Sortable.create(kolom, {
  group: "kanban", animation: 150,
  filter: "button, a, input, select",   // biarkan kontrol di dalam kartu tetap bisa diklik
  ghostClass: "opacity-50",
  onEnd: (evt) => fetch("/api/kanban", {
    method: "POST", headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ from: evt.from.dataset.col, to: evt.to.dataset.col, oldIndex: evt.oldIndex, newIndex: evt.newIndex })
  })
});
