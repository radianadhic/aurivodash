QRIS pada kartu memakai NMID merchant pemegang kartu, jadi QR yang ditampilkan bisa langsung dipindai aplikasi pembayaran.

Fitur halaman ini

  • Kartu 3D bisa dibalik — sisi belakang memuat kode QRIS
  • 3 kartu contoh (debit, kredit, virtual) dengan tema berbeda
  • Masking nomor kartu + tombol tampilkan/salin
  • QRIS dinamis per nominal dengan hitung mundur 5 menit
  • Payload EMVCo + CRC16 yang sah (bisa diverifikasi)
  • Unduh QR sebagai PNG atau salin payload ke papan klip
  • Limit harian, per transaksi, dan luar negeri
  • Blokir kartu lewat dialog konfirmasi bawaan template

Kode inti

// 1) bangun payload QRIS (EMVCo MPM) + CRC16
const teks = Qris.payload({
  nmid: "ID1024351287941",
  merchant: "AULIA SAPUTRA",
  kota: "JAKARTA",
  mcc: "5814",
  tipe: "dinamis",        // "statis" | "dinamis"
  nominal: 50000,
  keterangan: "INV-2026-0918"
});

// 2) gambar QR (SVG) — pustaka lokal, tanpa jaringan
Qris.render(document.querySelector("#kartu-qr"), teks, { logo: true });

// 3) verifikasi ulang CRC16 sebelum dikirim ke server
Qris.crcSah(teks);            // true
Qris.parse(teks);             // daftar tag: 00, 01, 51, 52, 53, 54 …
Tentang gambar. Panel logo di tengah QR hanya untuk tampilan; berkas PNG yang diunduh memuat QR murni (level koreksi M) supaya tetap mudah dipindai.
