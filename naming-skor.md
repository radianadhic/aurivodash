## 4. Temuan kunci v4

### a. AuriDash sudah dipakai merek aktif — hindari
`auridash.com` terdaftar **20 Okt 2025** (Tucows, nameserver Google Domains) dan
menyajikan toko daring dengan merek **"Auridash™"** (produk *NeonX*, US$49,99–109,99;
varian 7x17V, 9x37, 12x60). Simbol ™ menandakan klaim hak merek (common-law). Kelas
barangnya kemungkinan produk lampu/LED — berbeda dari kelas perangkat lunak — tetapi
konsekuensi praktisnya tetap: `.com` tidak bisa didapat, dan hasil pencarian nama akan
bercampur dengan merek orang lain.

### b2. Payung "Aurivo" tidak bebas di kanal praktis
Meski nama paket npm `aurivo` masih bebas, identitas tunggal **Aurivo** sudah dipegang
**Aurivo Co-operative Society** (Irlandia): `aurivo.com`, `aurivo.io`, `aurivo.net`,
`aurivo.app`, dan **organisasi GitHub `Aurivo`** (dibuka 16 Jun 2023, 0 repo publik).
Konsekuensinya: bendera **"Aurivo" saja tidak bisa dipakai** sebagai akun/repo/domain —
yang benar-benar bebas adalah bentuk gabungan **AurivoDash**.

### b. AuriDash dan AuroDash hanya beda satu huruf (i/o)
Ini pasangan yang sama bahayanya dengan **SeaDash/SeeDash**: jika kelak keduanya
dipakai (misalnya sebagai varian produk), keduanya akan tertukar saat ditulis. Pilih
**satu**, jangan pernah keduanya.

### c. Menambahkan deskriptor justru MEMBEBASKAN domain
Pola yang muncul berulang di riset ini:

| Merek tunggal | Status domain | Tambah deskriptor | Status domain |
|---|---|---|---|
| `aurivo.com` / `.io` / `.net` / `.app` | **terpakai** | `aurivodash.com` | **BEBAS (semua TLD)** |
| `plaindash.com` | terpakai (dorman) | — | — |
| `auridash.com` | terpakai (merek aktif) | `auridash.dev/.io/.id` | bebas |

Artinya: untuk merek baru, **"Nama + Kata Kategori" sering lebih mudah diamankan**
daripada nama tunggal — sekaligus menjelaskan produk tanpa tagline.

### d. Perbedaan "Aurivo Dash" vs "Aurivo UI"
- **Aurivo Dash** = merek + *produk* (Dash = dashboard). Bisa dipakai sebagai nama
  produk utama dan tetap mendukung sub-produk lain di bawah payung yang sama.
- **Aurivo UI** = merek + *kategori teknis*. Akurat (produk ini memang UI kit), tapi
  "UI" adalah namespace terpadat di front-end, dan kata itu **membatasi** begitu produk
  berkembang ke aplikasi/backend — serta tidak bisa mendukung sub-produk
  ("Aurivo UI Nasabah" terdengar janggal).

## 5. Arsitektur yang disarankan bila memilih Aurivo Dash

```
Aurivo              → merek payung (perusahaan / portofolio)
Aurivo Dash         → dashboard operator  (25 halaman)      ← produk utama
Aurivo Nasabah      → aplikasi mobile nasabah (9 layar)
Aurivo Grid         → modul MiniGrid / AG Grid
Auri                → persona asisten AI
```
Catatan merek: pada "Aurivo Dash", bagian **"Dash"** bersifat deskriptif sehingga dalam
pendaftaran merek biasanya *disclaimer* — kekuatan perlindungan praktisnya bertumpu pada
**"Aurivo"**. Karena itu: amankan **Aurivo** sebagai kata merek (word mark) lebih dulu,
lalu "Aurivo Dash" sebagai varian produk.

Selisih 0,10 poin → **praktis seri**. Perbedaannya bukan lebih baik/lebih buruk, tapi
*di mana* bentuk itu dipakai:

| Konteks | Bentuk | Contoh |
|---|---|---|
| Domain & URL | satu kata | `aurivodash.com`, `aurivodash.id` |
| Paket npm | satu kata | `npm i aurivodash` |
| Organisasi / repo GitHub | satu kata | `github.com/aurivodash/…` |
| Tagar & handle sosial | satu kata | `#AurivoDash`, `@aurivodash` |
| Judul halaman, logo, dokumen, README | dua kata | "Aurivo Dash — dashboard perbankan" |
| Merek dagang | ajukan **AURIVO** dulu, lalu AURIVO DASH | — |

**Data ketersediaan bentuk satu kata** — semuanya **bebas dan identik**: npm `aurivodash`,
`.com`, `.io`, `.dev`, `.id`, `.co.id`, `.app`, `.net`, `.ai`, serta handle GitHub
`aurivodash` (0 repo). Inilah satu-satunya identitas di seluruh riset ini yang **utuh
tersedia di setiap kanal**.

**Catatan teknis gaya penulisan**
- Kapital di tengah (**AurivoDash**) hanya hidup di prosa & logotype: URL dan nama
  paket tidak case-sensitive, sedangkan tagar sering ditulis huruf kecil semua. Jadi
  bedakan "Dash" lewat warna/ketebalan pada logotype, bukan hanya lewat huruf kapital.
- **Jangan klaim scope npm `@aurivo`** meski secara teknis bisa — itu memakai nama
  perusahaan lain (co-op Irlandia). Pakai nama paket polos `aurivodash`.
- Bentuk gabungan cenderung **lebih mudah didaftarkan sebagai satu merek utuh** (kata
  deskriptif "Dash" terserap ke dalam kata ciptaan), tapi ia lebih terikat pada produk
  dashboard; sedangkan payung **AURIVO** tetap yang menaungi sub-produk lain.

## 6. Batas riset

Skor ini **tidak** menyertakan pencarian merek terdaftar: **DJKI tidak dapat diakses** dari
lingkungan ini, begitu pula **USPTO/EUIPO** dan katalog ThemeForest. Kelas yang perlu dicek:

cuplikan hasil pencarian dan data RDAP — bukan dari halaman utuhnya.
